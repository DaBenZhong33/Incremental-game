# 筑长城 · 山河之间

单人第一人称建造与自动化网页试玩版。原二维样板保留在 `筑长城.html`，新版从 `index.html` 启动。

## 启动试玩

双击 `启动试玩.cmd`，或在本目录执行：

```sh
npm install
npm run dev
```

浏览器打开终端显示的本地地址。使用电脑端现代浏览器，需 Node.js 22 或以上。首次安装依赖需要网络，游戏运行不依赖外部素材。

## 游戏内容

第一人称采土、制坯、晾晒、研磨、烧砖；自由摆放设备，连接传送带、搬运路线与提升索道；雇工、升级背篓，修建三段城墙，最后点燃山巅烽火。无联机与敌袭。

WASD 移动，鼠标观察，E 操作，F 放入，G 抛下，B 营造册，Tab 地图，Esc 暂停。支持自动存档及导出、导入。营造册「工具与推车」可购买铁锹与实体独轮车，1/2 切换工具，E 握车、Q 停车、F 向设备卸货。

完整操作、配方、数值和验证范围见 [试玩说明](试玩说明.md)。

## 验证与构建

```sh
npm test
npm run test:browser
npm run build
npm run preview
```

浏览器测试默认使用本机 Chrome。构建输出在 `dist`，可发布到静态站点。开发服务器专用数值调试接口不会进入正式构建。

## 素材

场景和人物为程序生成模型；声音由 Web Audio 合成；渲染使用 Three.js（MIT）。不使用原作的美术或声音资产。
